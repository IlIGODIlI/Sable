# Sable
Multi-sensor landslide susceptibility classification system using Sentinel-1 SAR texture, Sentinel-2 spectral indices, and DEM geomorphic drivers. Features dynamic hyperparameter tuning (Scikit-Learn RandomizedSearchCV), tri-model benchmarking (RF 91.4% Acc / 0.975 ROC-AUC), and an interactive Streamlit early-warning dashboard.
